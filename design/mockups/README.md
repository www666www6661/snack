# Snack high-fidelity mockups

Open `snack-workbench.html` with one of these query values:

- `?screen=chat-light`
- `?screen=chat-dark`
- `?screen=review`
- `?screen=onboarding`
- `?screen=settings`

The source is a static design aid, not application code. Reference exports are generated at 1920×1080 into `../exports/`.
