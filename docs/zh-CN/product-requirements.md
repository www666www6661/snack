# 产品需求

状态：Baseline 1.0  
日期：2026-08-25  
产品显示名称：零食（临时）  
工程标识：`snack`

## 1. 产品目标

Snack 是 Codex CLI 与 Claude Code CLI 的跨平台、本地优先桌面前端。它把 Agent 的结构化事件转化为容易阅读和控制的聊天工作流，同时保留原生会话、认证、工具、安全限制和扩展生态。

成功标准：

- 用户无需长期阅读终端字符流即可完成真实编码任务。
- 多个 Agent 会话可以并行执行，等待授权或回答的状态不会被遗漏。
- 模型、推理强度和访问层级可在会话内调整，并从下一条消息生效。
- Agent 文件改动可被逐文件或逐修改块审查。
- 应用重启后能够恢复原生会话上下文和 GUI 工作现场。
- 所有能力来源于官方结构化接口；能力缺失时明确降级。

## 2. 用户与核心流程

主要用户是已经在本机安装并登录 Codex CLI、Claude Code CLI，且习惯在本地代码目录工作的开发者。

核心流程：

1. 应用检测本机 CLI、版本、登录状态和结构化协议能力。
2. 用户选择本地目录、Agent、安全配置并创建会话。
3. 用户发送文本、文件、文件夹、图片、Diff 或历史引用。
4. GUI 流式显示回复、推理、计划、工具调用、审批与错误。
5. 用户审查文件改动，并继续对话或打开外部编辑器。
6. 会话在托盘中继续运行，并可通过原生会话 ID 恢复。

## 3. 功能需求

### 3.1 Agent 与工作区

- `FR-AGENT-001` 每个会话固定绑定 Codex 或 Claude，创建后不可跨 Agent 切换。
- `FR-AGENT-002` 每个会话固定绑定一个本地工作目录；首版不支持 WSL、SSH、Dev Container 或远程目录。
- `FR-AGENT-003` 复用 CLI 原生登录与配置，不保存 API Key，不内置 CLI 安装器。
- `FR-AGENT-004` 启动时检测 CLI 路径、版本、认证状态和能力；允许手动指定可执行文件。
- `FR-AGENT-005` 设定最低 CLI 版本，并以协议握手或能力列表作为最终功能判断。
- `FR-AGENT-006` Codex 与 Claude 通过内部统一适配器接口实现；首版不开放第三方插件。

### 3.2 会话运行设置

- `FR-SET-001` 会话顶部持续显示 Agent、模型、推理强度、访问层级与运行状态。
- `FR-SET-002` 模型只能在当前 Agent 的可用模型内切换。
- `FR-SET-003` 模型、推理强度和访问层级修改只影响当前会话，从下一条消息开始生效。
- `FR-SET-004` 正在执行的请求继续使用发送时的配置；每条用户消息保存配置快照。
- `FR-SET-005` GUI 按 Agent 保存新会话默认配置，不回写 CLI 配置。
- `FR-SET-006` 不支持热切换时，等待当前请求结束，重启底层进程并通过原生会话恢复。
- `FR-SET-007` Token、上下文和费用只显示官方事件明确提供的数据，不自行估算。

### 3.3 消息输入与对话

- `FR-MSG-001` 输入区支持多行文本、草稿、发送、停止、附件预览和上下文提示。
- `FR-MSG-002` 支持工作区文件、文件夹、图片、截图、Diff、历史消息引用和 `@` 文件/符号搜索。
- `FR-MSG-003` 文件夹引用遵守忽略规则；默认排除 `.git`、依赖、构建产物和应用级排除目录。
- `FR-MSG-004` Agent 执行时支持“立即补充”和“排队发送”；不支持补充的协议自动降级为排队。
- `FR-MSG-005` 排队消息可编辑、排序、立即发送和取消；应用重启后不自动发送。
- `FR-MSG-006` 支持收藏提示词、参数模板和 `/` 命令菜单；模板不得执行任意脚本。
- `FR-MSG-007` 已发送消息和回复不可编辑、重试或重新生成。
- `FR-MSG-008` 新会话标题由当前 Agent 自动生成；失败时使用首条消息的截断文本。

### 3.4 消息渲染与事件

- `FR-EVENT-001` 对话以结构化事件呈现：消息、推理、计划、工具、命令、文件变化、审批、问题、错误和用量。
- `FR-EVENT-002` Markdown 支持代码块、表格、任务列表、链接、LaTeX 与 Mermaid；不允许任意 HTML。
- `FR-EVENT-003` 工具卡片默认折叠，展示摘要、状态、耗时和关键结果。
- `FR-EVENT-004` 官方协议返回的详细推理文本完整显示在可折叠区域；不尝试提取隐藏推理。
- `FR-EVENT-005` 计划同时显示在时间线计划卡片与可停靠任务面板，用户不能直接编辑 Agent 计划。
- `FR-EVENT-006` 单选、多选、确认和文本问题使用结构化交互卡片，一次提交一个问题。
- `FR-EVENT-007` 原始 Agent 协议与诊断面板只读；不提供 Agent 终端直接控制。
- `FR-EVENT-008` 本地开发服务 URL 仅作为普通链接交给系统浏览器。

### 3.5 文件、Diff 与编辑器

- `FR-DIFF-001` 提供只读文件预览和内置 Diff 审查器，不实现代码编辑器。
- `FR-DIFF-002` 支持按文件或修改块接受、拒绝；二进制文件只支持整文件操作。
- `FR-DIFF-003` 优先使用 Agent 官方隔离修改能力；不可用时对真实文件建立前后快照并安全反向应用。
- `FR-DIFF-004` 检测外部编辑冲突，不无提示覆盖用户或其他进程修改。
- `FR-DIFF-005` 现有脏工作区在用户确认后以当前内容作为会话基线。
- `FR-DIFF-006` 支持使用 VS Code、Cursor、系统默认编辑器或自定义命令打开文件并定位行列。
- `FR-DIFF-007` “接受”表示更新审查基线，不执行 `git add` 或提交；Snack 不替代 Git 客户端。

### 3.6 工作区写租约

- `FR-LOCK-001` 同一工作目录同一时间只有一个会话拥有 Agent 写权限。
- `FR-LOCK-002` 会话首次需要写入时申请 `WorkspaceWriteLease`，并持续持有直到用户释放、转移或关闭会话。
- `FR-LOCK-003` 其他会话只读运行；底层协议不能可靠限制只读时，阻止其执行。
- `FR-LOCK-004` 转移写租约前停止写操作并处理冲突；外部 Shell 和编辑器不受租约强制控制，但其变化标记为外部修改。

### 3.7 权限与安全模式

- `FR-PERM-001` 新会话选择严格确认、工作区自动或完全自动等访问层级。
- `FR-PERM-002` 权限请求显示结构化卡片，支持仅本次、本会话、始终允许和拒绝。
- `FR-PERM-003` 永久规则按操作、命令模式、路径和网络目标建模，并可查看、编辑、禁用和删除。
- `FR-PERM-004` 高风险操作可强制确认，GUI 永不绕过 CLI 原生限制或组织策略。
- `FR-PERM-005` 工具参数与协议日志在应用内原样显示；系统钥匙串内容不得主动写入日志。

### 3.8 会话与窗口管理

- `FR-SESSION-001` 支持新建、重命名、删除、置顶、归档、标签、全文搜索、分组和保存筛选视图。
- `FR-SESSION-002` 支持按目录、Agent、模型、状态、标签和时间筛选。
- `FR-SESSION-003` 支持 Markdown/JSON 导出；会话复制仅复制记录，不自动重建 Agent 时间线。
- `FR-SESSION-004` 多个会话可并行执行，侧边栏显示空闲、执行、等待审批、等待回答、完成、失败和断开。
- `FR-SESSION-005` 主窗口一次显示一个完整聊天；其他会话可弹出独立窗口。
- `FR-SESSION-006` 主窗口使用可停靠、浮动和保存布局的专业工作台，默认保持对话优先。
- `FR-SESSION-007` 全局单实例；再次启动通过仅当前用户可访问的 IPC 激活现有实例。
- `FR-SESSION-008` `snack <目录>` 打开该目录最近使用的会话；没有历史时进入预填目录的新建页。

### 3.9 Shell 终端

- `FR-TERM-001` 每个会话提供与 Agent 进程分离的本地 Shell，并支持多个标签。
- `FR-TERM-002` 终端支持 ANSI/VT、PTY/ConPTY、复制、粘贴、搜索、字体与缩放。
- `FR-TERM-003` 终端标签可拖出为独立窗口，不支持窗格拆分。
- `FR-TERM-004` 托盘运行期间 Shell 保持运行；真正退出后终止进程。
- `FR-TERM-005` 重启后恢复标签元数据并创建全新 Shell，不重跑命令，不保存滚动历史。

### 3.10 持久化、备份与恢复

- `FR-DATA-001` GUI 保存结构化事件索引、原始日志、布局、权限、模板和未审查 Diff；对话上下文优先由原生会话恢复。
- `FR-DATA-002` SQLite 保存元数据，大对象使用压缩、去重的内容寻址存储。
- `FR-DATA-003` 聊天和日志普通本地保存；敏感配置和永久授权使用系统钥匙串。
- `FR-DATA-004` 默认日志与已审查快照保留 30 天，总空间上限 10 GB；未审查数据不得自动清理。
- `FR-DATA-005` 支持普通或密码加密的完整手动备份，不导出 CLI 凭据或钥匙串敏感数据。
- `FR-DATA-006` 恢复采用完全替换，恢复前自动备份当前数据，并支持失败回滚和目录重新映射。
- `FR-DATA-007` 重启时自动恢复退出前运行或等待的会话上下文，但不自动重发中断请求或排队消息。

### 3.11 桌面行为

- `FR-DESKTOP-001` 点击关闭窗口缩小到托盘，所有 Agent 与 Shell 继续运行；真正退出时确认并正常终止。
- `FR-DESKTOP-002` 系统通知只显示通用状态，不显示标题、目录或消息内容。
- `FR-DESKTOP-003` 提供固定跨平台快捷键和全局界面缩放；不提供自定义快捷键或 Vim 模式。
- `FR-DESKTOP-004` 支持浅色、深色、跟随系统和声明式 JSON 自定义主题。
- `FR-DESKTOP-005` 用户可分别选择系统界面、聊天和等宽字体。
- `FR-DESKTOP-006` 首发简体中文和英文，并建立可扩展 Qt 国际化框架。

## 4. 非功能需求

- `NFR-001` 技术栈为 C++20、Qt 6.8 LTS+、Qt Widgets、Qt WebEngine 与 CMake。
- `NFR-002` 保证 Windows 10/11、Debian 13、Ubuntu 22.04 LTS；macOS 跟随 Qt 官方范围。
- `NFR-003` 架构目标为 Windows x64、Linux x64/ARM64、macOS Intel/Apple Silicon。
- `NFR-004` 主窗口最小 1280×800，高保真设计基准 1920×1080，并适配 125%-200% DPI。
- `NFR-005` 主线程不执行协议读取、索引、Diff、文件快照或大型数据库操作。
- `NFR-006` Snack 不收集遥测、不上传崩溃报告、不请求麦克风权限。
- `NFR-007` 第一方代码总体行覆盖率至少 80%，所有测试、格式和基础警告检查通过后方可合并。
- `NFR-008` 第三方依赖数量受控，使用 CMake `FetchContent` 锁定版本，并生成许可证清单。

## 5. 明确不在首版范围

- 直接调用 OpenAI 或 Anthropic API。
- 远程执行、WSL、SSH、容器或工作区同步。
- 内置完整代码编辑器、Git 客户端、Web 预览器或端口管理器。
- MCP、Skills、Plugins 的配置和安装管理。
- 第三方 Agent 插件、语音功能、应用级 PIN、生物认证和完整无障碍认证。
- 自动更新、自动上传诊断、任意 HTML、主题脚本和终端屏幕解析。

## 6. 发布边界

- 版本使用 SemVer，从 `0.1.0` 开始。
- Windows：x64 MSI。
- Linux：amd64/arm64 `.deb`。
- macOS：未签名、未公证的 Intel 与 Apple Silicon `.app` 压缩包。
- 源码公开，提供 CMake 构建说明，许可证为 MIT。
