# 安全与权限模型

## 1. 信任边界

Snack 信任当前操作系统用户，但不信任 Agent 输出、工作区内容、Markdown、工具参数、主题文件、备份文件或外部 URL。CLI 和扩展可能联网；“Snack 不收集数据”不代表底层 CLI 不联网。

## 2. 访问层级

GUI 提供稳定语义，适配器映射到各 CLI 官方策略：

| GUI 层级 | 语义 |
|---|---|
| 严格确认 | 敏感命令、写文件、网络与越界访问逐次确认 |
| 工作区自动 | 工作区内常规读写自动允许，高风险、网络或越界仍确认 |
| 完全自动 | 使用 CLI 允许的最高自动化，但组织策略和强制确认仍优先 |

映射结果必须可检查。某 Agent 无法表达等价策略时，显示具体差异并使用更严格的有效策略。

## 3. 审批状态

审批请求绑定 `conversationId`、`turnId`、原生 request ID和 tool/item ID。决策包括 once、session、always、deny/cancel，但只有协议支持的决策才显示。重复或重连后的请求按原生 request ID幂等处理。

永久规则不是原始字符串白名单。规则至少包含操作类型、命令 argv/pattern、canonical path范围、网络 host/protocol/port、Agent 类型和创建来源。高风险规则可被系统策略否决。

## 4. 强制安全约束

- 工作区写租约优先于会话“完全自动”。
- 无法可靠强制只读时，不启动只读会话的 Agent 执行。
- 危险目录、提权、批量删除、凭据位置和未知越界目标可以强制确认。
- 不使用 shell 拼接处理 CLI 路径或用户参数；使用 argv 数组。
- Agent 进程继承最小必要环境，但不删除 CLI 认证所需环境。
- Snack 不修改 Codex/Claude 的用户扩展配置。

审查拒绝遵循“比较后写入”：文件哈希必须仍与用户看到的 Diff 哈希一致，替换使用原子写入；不一致即外部编辑冲突，绝不覆盖任一方。写租约使用 Canonical、大小写规范化的工作区身份，路径别名不能并行取得所有权；Owner 销毁会释放当前进程内租约，未来跨进程租约必须先增加操作系统支持的恢复记录，才能替换此边界。

## 5. WebEngine 与内容

消息不是可信 HTML。Markdown 解析关闭 HTML 与图片，再由 DOMPurify 移除脚本、事件属性、iframe、用户任意样式、媒体/表单和资源属性。KaTeX 使用 `trust: false`；Mermaid 使用禁止 HTML Label 的严格模式，产出的 SVG 再清理一次。禁止联网的 CSP 与 C++ 请求拦截器分别独立拒绝远程子资源和本地文件 URL。外链必须回到 C++，且只允许校验后的 HTTP(S)/`mailto:`。自定义主题只能提供通过 Schema 校验的 JSON 颜色 Token，不能包含 QSS/CSS/JS。

Renderer 无法通过 WebChannel 得到工具参数、工作区路径、任意命令或 Agent 句柄，无痕 Profile 不持久化 Cookie 或缓存。普通测试禁用 WebEngine 并使用纯文本降级；独立的 MSVC/Qt 官方构建测试只从 qrc 渲染恶意 Markdown，在 C++ 边界检查链接，绝不启动浏览器或访问主机。

## 6. 数据保护

- CLI 登录凭据由 CLI 管理，Snack 不读取或复制。
- 敏感配置与永久授权的秘密部分使用 Windows Credential Manager、macOS Keychain 或 Linux Secret Service。
- 聊天、日志与快照使用普通本地文件权限；应用内原样显示协议已经返回的敏感值。
- 系统通知只包含通用状态。
- 无遥测、无崩溃上传、无诊断包上传。

## 7. 备份与恢复

普通备份明确提示可能包含源码、路径和秘密。加密备份使用成熟的密码派生与认证加密库；密码不保存且无法找回。恢复防止路径穿越、符号链接逃逸、压缩炸弹、重复条目和超限文件。所有内容先在临时区域校验，再原子替换。

## 8. 单实例 IPC

IPC 只允许当前用户连接。消息 Schema 只接受激活窗口和打开本地目录等有限命令。目录必须存在并规范化；IPC 不接受任意命令、环境变量或提示词。

## 9. 威胁验证清单

- 恶意 Markdown、Mermaid 和链接。
- 伪造/重放审批请求。
- 工作区符号链接逃逸与大小写别名。
- Agent、Shell、外部编辑器并发写入。
- 数据库/备份损坏和迁移中断。
- 超大协议帧、输出洪泛、慢消费者和进程卡死。
- 恶意主题、附件名、终端控制序列和 ZIP路径。
- WebEngine 子进程崩溃及 Qt 资源加载失败。

这些路径必须有自动化测试或发布前手动安全检查。
