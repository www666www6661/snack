# UX 与交互规格

## 1. 体验原则

1. **对话优先**：默认界面只展示理解任务所需信息。
2. **状态诚实**：区分执行、等待、失败、降级和未知，不使用虚假百分比。
3. **渐进披露**：工具、推理、原始协议和专业面板按需展开。
4. **可恢复**：取消、断连、冲突和崩溃都保留现场与下一步操作。
5. **单一控制点**：同一会话只有一个可输入聊天视图，避免重复提交。

## 2. 默认主窗口

1920×1080 基准布局：

- 左侧 280 px 会话栏：新建、搜索、保存视图、会话状态。
- 中央聊天区：顶部会话控制、时间线、底部 Composer。
- 右侧辅助 Dock 默认关闭；打开 Diff/任务时建议宽 520-680 px。
- 底部终端 Dock 默认关闭，高度建议 280-360 px。

1280×800 时折叠会话栏为图标/抽屉，辅助 Dock以覆盖或单面板切换呈现。主窗口禁止小于 1280×800。

## 3. 顶部会话控制

从左到右：Agent 标识、标题、工作目录摘要、连接/写租约状态；右侧为模型、推理强度、访问层级和更多操作。运行中改变控件时显示“下一条消息生效”。不支持的选项禁用并提供原因。

标题栏正下方使用持久诊断条展示 Agent 回退、连接丢失或重连过程。回退 Agent 仍在使用时，回退说明始终可见；连接失败保留原始诊断并在诊断条内提供“重新连接”；重试期间继续显示上一次失败原因，直到原生握手真正成功后才清除。状态栏可以同步提示，但不能成为唯一信息入口。`Closed` 是终止状态：异步退出 Agent 的迟到连接、能力、原生身份或事件信号不能重新打开会话、替换诊断或追加时间线数据。

## 4. 时间线

- 用户消息靠右但不使用高饱和大色块；Agent 内容占主阅读列。
- 工具卡片用单行摘要 + 状态图标 + 耗时；展开后显示原始输入输出。
- 推理完成后默认折叠，标题说明是“推理”还是“推理摘要”。
- 权限卡片使用清晰目标、风险和决策按钮，视觉优先级高于普通工具卡。
- 问题卡只提交当前问题；提交后显示只读答案。
- 计划卡显示当前步骤，任务 Dock显示完整步骤与关联事件。
- 中断、恢复失败和结果未知使用持久状态块，不能自动消失。

## 5. Composer

Composer 包含附件/`@`/模板/`/` 入口、自动增长文本区、当前发送模式和发送/停止按钮。执行中发送按钮菜单提供“立即补充”和“排队发送”。队列显示在 Composer 上方，可编辑排序。权限或问题待处理时，焦点优先转到对应卡片。

当前 M3 Composer 会随文本换行自动增高到受限阅读高度，并遵循下方固定快捷键。草稿按会话 UUID 保存在本地，停止输入片刻后防抖写入，关闭窗口时再次强制保存。成功发送或成功排队会立即清除草稿；用户主动发送前，草稿不会成为事件或 Agent 输入。

`/` 按钮和输入框开头的 `/` 按键会打开收藏提示词模板。模板只保存纯文本，仅支持显式 `{{参数}}` 占位符；插入时逐项填写唯一参数，按字面替换后留在 Composer 中供用户检查。菜单可以把当前输入保存为模板，也可移除已有模板；它绝不运行脚本、命令或工作区替换逻辑。

## 6. 关键流程

### 新建会话

选择目录 → 显示脏工作区提醒 → 选择 Agent → 显示可用性 → 选择 GUI 默认模型/强度/访问 → 显示实际修改模式与只读能力 → 创建。任何错误保留表单状态。

### 权限

卡片先回答“Agent 想做什么、对哪里、为什么、风险是什么”，再显示协议允许的决策。永久授权二次确认并展示规则范围。

### Diff 审查

文件列表按未审查/冲突/已接受/已拒绝分组。中间显示统一 Diff；顶部提供整文件接受/拒绝；hunk 操作贴近对应块。冲突时禁用拒绝并显示外部变化定位。

### 会话恢复

启动时显示非阻塞恢复中心。每个会话展示正在连接、已恢复、已中断或失败。会话断开时在标题栏提供“重新连接”，恢复原生上下文但不重试被中断的 Turn，也不重放排队消息。中断请求不提供重试按钮，只提供“打开会话”。

### 退出

关闭窗口进入托盘。真正退出对话框分列 Agent 与 Shell 任务，说明会中断且不会自动重发，然后允许取消或退出。

## 7. 面板与窗口

可停靠面板：会话、文件、Diff、任务、权限中心、原始协议、终端、详情。内置布局：专注对话、代码审查、终端调试、多会话监控。独立聊天窗口和终端窗口保存位置，但显示器丢失时回到可见区域。

## 8. 会话导航

会话栏支持分组、置顶、标签、归档和保存视图。状态在标题前使用形状+文字/提示，不只依赖颜色。全文搜索默认覆盖消息、回复、工具摘要和路径；原始协议日志可选。

## 9. 固定快捷键

| 操作 | Windows/Linux | macOS |
|---|---|---|
| 新建会话 | `Ctrl+N` | `Cmd+N` |
| 搜索会话 | `Ctrl+K` | `Cmd+K` |
| 聚焦输入 | `Ctrl+L` | `Cmd+L` |
| 发送 | `Enter` | `Enter` |
| 换行 | `Shift+Enter` | `Shift+Enter` |
| 排队发送 | `Ctrl+Enter` | `Cmd+Enter` |
| 停止当前任务 | `Esc`（输入空闲时） | `Esc` |
| 打开 Diff | `Ctrl+Shift+D` | `Cmd+Shift+D` |
| 打开终端 | `Ctrl+J` | `Cmd+J` |
| 缩放 | `Ctrl +/-/0` | `Cmd +/-/0` |

直接操作 Shell 时不拦截终端常用组合键，应用级操作通过菜单仍可访问。

## 10. 文案与通知

GUI 文案本地化，CLI 原始错误原文保留。系统通知只用“一个任务已完成”等通用内容。危险操作使用具体动词和目标，不使用模糊“确定吗”。
